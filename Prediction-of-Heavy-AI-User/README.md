# 🤖 Prediction of Heavy AI User
Analyzed 15,000 user records to predict AI 'Heavy Users', comparing three machine learning models. The best model achieved ROC-AUC of 0.76 and Recall of 66.6% for the heavy user category. This approach emphasizes detecting users with high AI usage, over simple accuracy, in order to support targeted strategies.

## Technologies Used
* **Python** — core language used for the analysis
* **Pandas** — data manipulation and cleaning
* **Scikit-Learn** — preprocessing pipeline, model training, GridSearchCV/RandomizedSearchCV
* **Matplotlib** — statistical visualizations
* **Jupyter** — interactive, documented analysis environment
